Browser-only utility

Wind Waker HD
Save Editor

Edit a focused set of high-confidence fields in cking.sav. Your save stays entirely on your device.

No server. No upload. The site has no analytics, API calls, accounts, or backend.
!
Back up the entire Cemu save directory first.

This tool creates a modified copy. Never overwrite your only known-good save.

Where is cking.sav?

In Cemu, right-click Wind Waker HD, choose Save directory, then open the numbered user folder. Copy cking.sav somewhere safe before editing.

Pending changes

Checksums are recalculated automatically. The original file in your browser session is never overwritten.

Deliberately limited scope

This first version does not edit story flags, charts, dungeon state, return locations, Second Quest status, playlog data, Miiverse data, or pictographs. Those areas are more interconnected and deserve separate, carefully tested tools.
